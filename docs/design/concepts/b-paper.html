Most overlay tools give you a colour picker and four sliders. crshhx gives you the geometry: per-arm length and thickness, gap, rotation, outlines, centre dot, spread ring and glow — drawn above the game exactly as you set them, and organised in a library that stays on your machine.

01 / Designer

The editor draws what the overlay draws.

There is no preview approximation. The editor works on the overlay’s own schema, so the reticle you compose is the reticle the game sees.

  • ArmsPer-arm presence, length 0–12 and thickness 0–6
  • Gap−4 to 12, including negative overlap
  • OutlineOuter and inner, 0–6, own colour and opacity
  • Centre dotSquare or round, 0–6
  • RingSpread ring, radius and thickness
  • TransformRotation in 15° steps, scale, offset
  • CompareDiff a held snapshot against the working copy

02 / Library

258 presets, filed not fused.

Organisation metadata lives in a sidecar keyed by preset id, so filing, renaming or favouriting a built-in never modifies it, and a shipped preset cannot be overwritten by an edit or an import.

Search and sort by name, game, recency or favourite, with counts that stay correct. Favourites are a single store; the legacy key is migrated on first read.
