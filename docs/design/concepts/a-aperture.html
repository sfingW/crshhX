01 — DESIGNER

Edit the reticle,
not a description of it.

Per-arm length and thickness, gap, rotation, scale, outer and inner outlines, centre dot, spread ring and glow. Colour tools report contrast against the target backdrop while you pick, every change is undoable, and a held snapshot can be diffed against the working copy parameter by parameter.

02 — WEAPON SLOTS

The crosshair changes
when your weapon does.

Record the key that selects each weapon and bind a reticle to it: shotgun on 1, rifle on 2, SMG on 3, sniper on 4, utility on 5, all rebindable. The keyboard is observed passively and nothing is consumed, so the game receives every keypress exactly as it would without crshhx.
